<div class="tq-card" markdown>

### Technical indicators

A widely varied collection of modular, hand-selected momentum and candlestick
pattern indicators that provide early detection of changes in the direction
of price trends.
</div>

<div class="tq-card" markdown>
<span class="tq-card__icon">:material-vector-line:</span>
### Support / resistance

Support and resistance algorithms combined through a fair voting mechanism
for high accuracy and confidence.
</div>

<div class="tq-card" markdown>
<span class="tq-card__icon">:material-lightning-bolt-outline:</span>
### Parallelisation

Multiprocessing and multithreading run strategy calculations in parallel,
increasing throughput.
</div>

<div class="tq-card" markdown>
<span class="tq-card__icon">:material-memory:</span>
### Memoization

Thread-safe, file-based caches for expensive indicator calculations speed up
backtesting and live predictions.
</div>

<div class="tq-card" markdown>
<span class="tq-card__icon">:material-cloud-outline:</span>
### Cloud orchestration

Google Cloud Run Jobs execute long-running tasks in parallel for better
throughput and responsiveness.
</div>

<div class="tq-card" markdown>
<span class="tq-card__icon">:material-source-branch:</span>
### DevOps

A one-click push-to-main CI/CD pipeline builds and deploys Docker images and
Cloud Run Jobs with GitHub Actions and Terraform.
</div>

<div class="tq-card" markdown>
<span class="tq-card__icon">:material-puzzle-outline:</span>
### Software design

Loosely-coupled, cohesive classes with plug-and-play multi-vendor support
(e.g. Yahoo Finance, Alpha Vantage).
</div>
